# Proyecto

Es un solo proyecto Remotion con dos composiciones (`Root.tsx` importa `Calentador.tsx` y `ChatGPT.tsx`). Para ejecutarlo, junta las carpetas `src/` de `calentador/proyecto` y `chatgpt/proyecto`, haz `npm install` (versiones fijadas en `package.json`), pon `voz.wav` del kit en `public/<tema>/` y las fuentes en `public/fonts/`, y ejecuta `./render.sh Calentador out/v1.mp4` o `./render.sh ChatGPT out/v1.mp4`. `*.v2.tsx` = versión tras la corrección (solo cambian `ACCENT` y la hora del primer rótulo).
